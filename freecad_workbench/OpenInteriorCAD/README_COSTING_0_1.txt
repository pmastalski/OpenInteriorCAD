OpenInteriorCAD — Costing 0.1

NEW COMMAND:
Cost Estimate

Material Library now also stores:
- Price
- Price Unit

Default price units:
- Board / Front / Back -> m²
- Edge -> m

Cost Estimate combines:
- Carcass board cost
- Front material cost
- Back material cost
- Edge-band cost
- Hardware cost

SOURCE OF QUANTITIES:
- Board Parts
- Cut List metadata
- Edge Assignment
- Hardware automatic quantities / overrides

SOURCE OF PRICES:
- Material Library
- Hardware Library

SELECTION:
- selected cabinets -> calculate selected cabinets only
- no cabinet selected -> calculate entire project

SUMMARY:
- Carcass
- Fronts
- Backs
- Edges
- Hardware
- TOTAL

CSV:
- detailed production cost rows
- category summary
- UTF-8 BOM
- semicolon separator

IMPORTANT:
Costing 0.1 does NOT modify cabinet geometry.
No accepted corner geometry was changed.
No front geometry was changed.
