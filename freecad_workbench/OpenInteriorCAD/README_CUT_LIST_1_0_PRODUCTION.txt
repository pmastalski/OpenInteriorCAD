OpenInteriorCAD — Cut List 1.0 / Production

NEW PRODUCTION STRUCTURE

Detailed Parts:
- Category
- Cabinet
- Part / Role
- Qty
- Length / Width / Thickness
- Material
- explicit Front / Back / Left / Right edge assignments
- edge material / thickness / length
- board area

Production categories:
- Carcass
- Fronts
- Backs

Board Summary:
- category
- material
- thickness
- total number of parts
- total board area
- cabinet count

Edge Summary:
- edge material
- edge thickness
- total running metres
- number of affected parts

Category filter:
- All
- Carcass
- Fronts
- Backs

Exports:
1. Export Detailed CSV
2. Export Production Summary CSV

Production Summary CSV contains:
- BOARD MATERIALS section
- EDGE BANDS section
- TOTALS section

CSV:
- UTF-8 BOM
- semicolon delimiter
- suitable for Excel in Polish/European locale

IMPORTANT:
No cabinet Shape code was changed.
No corner-cabinet geometry was changed.
No material-assignment logic was changed.
Cut List 1.0 only reads existing Board Parts production metadata.
