OpenInteriorCAD — Blind Corner Base 0.1

NEW CABINET TYPE:
Blind Corner Base

DESIGN:
This is a straight elongated rectangular corner cabinet, NOT an L-shaped
corner cabinet.

The cabinet consists of:
- normal rectangular outer carcass
- hidden closed box on the Left or Right side
- full-height partition separating the hidden box from the usable cabinet
- internal front closure panel that closes the hidden box
- visible spacer filler (blenda dystansowa) next to the usable front
- shelves only in the usable compartment
- continuous recessed plinth

EDIT FURNITURE — NEW GROUP:
Blind Corner

Controls:
- Hidden Side: Left / Right
- Blind Box Width
- Spacer Filler

DEFAULT PRACTICAL DIMENSIONS WHEN SWITCHING FROM A 600 mm CABINET:
- Overall Width: 1200 mm
- Blind Box Width: 600 mm
- Spacer Filler: 100 mm
- Depth remains the cabinet Depth

FRONTS:
The usable compartment supports:
- Open
- Single Door
- Double Door
- Drawers
- Door + Drawers
- Lift-up

The decorative Spacer Filler is always visible on the hidden side.

FRONT OPENING:
Single/Double doors and drawers use the existing Front Opening properties.
The opening axes are calculated from the usable compartment, not from the
overall elongated cabinet width.

PRODUCTION:
Board Parts / Cut List include:
- Left Side
- Right Side
- Bottom
- Top
- Back
- Partition Side
- Blind Closure
- Shelf(s)
- Plinth
- Spacer Filler
- usable front(s)

Therefore the new cabinet is also available to:
- Cut List
- Cut Layout
- PDF/SVG cut-layout export
- material costing based on Board Parts

IMPORTANT:
The accepted existing Corner Base / Corner Wall L-shaped geometry is not
modified by this package.
